# 周末本地活动 Agent — 设计说明（技术版 + 人话说明）

> 纯技术版见 [DESIGN.md](./DESIGN.md)

**目标**：自然语言 + 出发点 → **4–6 小时半日行程**（玩 → 吃 → 可选加项），演示订座/排队/分享闭环。  
**规划入口**：`shared/planning/` ← `plan-api.ts` / Edge `plan`  
**推荐模式**：AI 听懂 + 写文案；选店由规则 DAG 完成。

> **人话**：选好出发点说一句话，小喵给出下午能走的行程。AI 不选店、不自动订餐厅；你在行程表里点「立即预定」。店铺是演示数据。

---

## 1. Planning 策略

### 1.1 总体思路

| 阶段 | 职责 | 实现 |
|------|------|------|
| 理解 | 话术 → 约束 | 规则 ∥ 出发点 ∥ AI 语义 → 融合 |
| 召回 | 筛候选 | 三池并行 → 顺路 → 不够则放宽重试 |
| 推荐 | 定一条线 | 玩+吃+加项 组合打分 |
| 编排 | 时间表 + Mock | 排队/订座只记日志；**界面不自动订好** |
| 展示 | 摘要 + 表 + 追问 | chat 润色，不改已选店 |

POI：北京 **34 商圈** Mock（`beijing-zones.ts`，含 **798**）；太远全城兜底。

> **人话**：听懂 → 捞店 → 选最优线 → 排时间。和以前不同，规划完不会偷偷标「已预定」。

### 1.2 约束理解

**规则**：默认下午走、最远距离、亲子/朋友、孩子年龄、人数、低脂、商圈词。  
**AI**：只补 JSON，**不给店名**。  
**融合**：太远不要；提到商圈加分；「别太远」优先于 AI 放大范围。

> **人话**：三路同时理解你的话和位置。AI 不说「去某某店」。

### 1.3 召回

每池约 8 家：距离与场景过滤 → 打分（相关/距离/履约/商圈）→ 避免全挤同一商圈。不要加项就只筛玩和吃。玩得好的附近，餐厅加分。不够就放宽距离和时间再试（最多 2 次）。

> **人话**：先粗筛再精排，顺路很重要。

### 1.4 推荐

试玩+吃+加项组合，选总分最高；餐厅满座同池换有座的。时间轴：玩 → 20 分钟 → 吃 → 15 分钟 → 加项。

> **人话**：定一条你能走完的线。

### 1.5 场景

家庭偏亲子户外；朋友偏聚餐社交。识别不出默认家庭。

## 2. 工具调用链路

### 2.1 链路总览

```text
用户发送
  ├─ 改行程（如加 798）→ 只改表，不重算
  ├─ 追问（继续探索等）→ 只聊天，带记忆
  └─ 新规划 → plan → 行程表（全未预定）→ 短摘要
```

> **人话**：三种发消息方式。摘要说要点，表上可操作；继续探索在 **表格下面**。半日不推荐住宿。

### 2.2 工具清单

| 工具 | 真/假 | 说明 |
|------|-------|------|
| AI 语义 / chat | 真 | 听懂、写字、追问 |
| 搜店 / hold_table | 假 | 只记日志；**不自动订座** |
| 行程表「立即预定」 | 前端 | 你点了才算预定 |

### 2.3 新规划成功路径

听懂 → 捞店 → 组合 → Mock 备注 → **表全未预定** → 短摘要 → 你手点预定。

## 3. 异常处理

理解失败不凑假行程；候选不够先放宽；满座换店；润色挂了行程表还在；追问别重复推荐、别瞎编店名；加不上的 POI 会提示。

| 情况 | 你会看到 |
|------|----------|
| 没出发点 | 先选位置 |
| AI/Key 问题 | 规划失败 |
| 附近没店 | 失败或提示放宽 |
| 润色失败 | 仍有行程表 |

> **人话**：听不懂就失败；表是底线。出问题看 `toolTrace` 和 `M-TraceId`。

## 4. 前端与持久化

**页面**：短摘要 → 行程表（删/换/预定）→ 继续探索 → 地图。

**侧栏**：真会话，可新建/切换/删除；空对话不会连堆「新对话」。

本机记住：聊天、行程 Tab、收藏。刷新还在；换设备没有（未做云同步）。

| 真 | 假 |
|----|-----|
| AI + 规则选店 + 你点预定 | 真实美团检索/自动订座 |

> **人话**：侧栏不是假标题了。清浏览器数据会丢。

## 5. 运行（简）

```bash
npm install && npm start
```

**自测**：望京带娃半日 → 点继续探索 → 加 798 → 手点预定。  
**示例**：家庭 —「今天下午带5岁孩子出去3小时，别太远，老婆减肥」；朋友 —「下午想和两男两女朋友玩4小时，附近就行」。

> **人话**：本地 `npm start`，`.env` 配 `FRIDAY_APP_ID`；上线 deploy `plan` `recommend` `chat`。
